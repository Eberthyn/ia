A

Agente (de IA)

Sistema baseado em um modelo de linguagem que, além de conversar, executa ações por você, diretamente no computador ou na internet, como abrir arquivos, preencher documentos ou buscar informações. As skills são recurso típico dos agentes, embora alguns chatbots também as aceitem (ver skills).

Ajuste fino (fine-tuning)

Treinamento adicional, em escala menor, com dados curados, para especializar o modelo em uma tarefa ou domínio (jurídico, médico, atendimento ao cliente).

Alucinação

Saída fluente e confiante, porém factualmente errada.

Automelhoria (self-refine)

Procedimento em que o mesmo modelo gera uma resposta, critica essa resposta e a reescreve incorporando a própria crítica. Rende mais quando a crítica solicitada é específica.

C

Cadeia de pensamento (chain-of-thought)

Técnica que pede ao modelo que detalhe o raciocínio em etapas antes da resposta final, por exemplo com a instrução "vamos pensar passo a passo". Mostrar o raciocínio não garante que ele esteja correto.

Cibercondria

Ansiedade induzida pela busca on-line por informações sobre saúde.

D

Desidentificação

Definição pendente

E

Engenharia de prompt

Prática de formular deliberadamente o texto enviado ao modelo para orientar a resposta na direção do resultado desejado. Não torna o modelo confiável, mas o torna mais dirigível (ver Prompt e PaCTO).

I

Inferência

É o que acontece quando você usa o modelo (rápida, feita a cada interação).

J

Janela de contexto

Quantidade máxima de tokens que o modelo consegue "ver" de uma vez (entrada + saída). Modelos atuais variam de 8 mil a 2 milhões de tokens. Se o seu material excede a janela, partes serão ignoradas silenciosamente.

L

LLM (large language model)

Modelo de linguagem que gera texto prevendo o próximo token a partir dos anteriores, token após token. Essa mecânica explica tanto a fluência do texto quanto a possibilidade de erro factual (ver Token e Alucinação).

M

Markdown

Modo de formatar texto com poucos símbolos, em que uma cerquilha (#) marca um título, duas cerquilhas (##) marcam um subtítulo e dois asteriscos em volta de uma palavra a colocam em negrito. Em prompts longos, serve para separar cada parte sob um título próprio.

Meta-prompting

Uso de um prompt para gerar ou melhorar outro prompt: em vez de pedir que a IA execute a tarefa, pede-se que ela ajude a escrever o pedido. O prompt sugerido é ponto de partida e deve ser revisado antes do uso (ver Prompt).

Modelo aberto

Pesos do modelo disponíveis publicamente, podendo ser baixados e rodados localmente (ex.: Llama, Mistral, Qwen).

Modelo fechado

Acessível apenas via interface web ou API da empresa (ex.: GPT-4, Claude). Para o SUS, modelos abertos têm vantagens importantes em soberania e proteção de dados.

Multimodalidade

Capacidade do modelo de processar mais de um tipo de entrada (texto + imagem, texto + áudio). Modelos atuais como GPT, Claude e Gemini são multimodais.

P

PaCTO

Método que organiza um prompt em quatro blocos — Papel, Contexto, Tarefa e Output —, cada um respondendo a uma pergunta que o modelo não teria como responder sozinho: de que ponto de vista e para quem escrever, o que precisa saber, o que deve fazer e como deve entregar (ver Engenharia de prompt).

Parâmetro

Cada um dos números internos da rede neural, ajustados durante o treinamento. Modelos atuais têm de bilhões a centenas de bilhões de parâmetros. Não confunda com prompt, pois parâmetros são internos ao modelo; prompts são a sua entrada.

Pré-treinamento

Primeira etapa de como o modelo aprende, com exposição massiva a texto bruto, para aprender a prever o próximo token.

Priming (preparação do conhecimento)

Procedimento em duas etapas: primeiro o modelo resume o que se sabe sobre o tema; depois, usa esse resumo para responder à pergunta específica. Na literatura em inglês, aparece como generated knowledge prompting.

Projetos

Recurso das ferramentas de IA que guarda instruções e arquivos para reaproveitá-los em todas as conversas criadas dentro dele; o nome varia conforme a ferramenta. Todo projeto tem três partes: um nome, um campo de instruções fixas e uma área para anexar arquivos (ver skills).

Prompt

O texto que você fornece ao modelo como entrada — incluindo pergunta, instruções e quaisquer documentos colados. Tudo o que você escreve e envia ao modelo: cada mensagem que você digita e confirma, seja uma pergunta de uma linha, seja um texto longo com instruções e um arquivo anexado. É o seu lado da conversa. A qualidade do prompt determina, em grande medida, a qualidade da saída (ver Engenharia de prompt).

R

RLHF (Reinforcement Learning from Human Feedback)

Aprendizado por reforço com feedback humano. Etapa em que o modelo é ajustado para se aproximar das preferências de avaliadores humanos.

S

Skills

Procedimentos reutilizáveis que um agente de IA guarda e aciona sozinho quando a tarefa aparece, como formatar um relatório num padrão fixo. Costumam ser criadas pela própria IA a partir de uma conversa em que a tarefa deu certo: enquanto o projeto guarda o contexto, a skill guarda o método (ver Agente e Projetos).

T

Temperatura

É o parâmetro que controla a "criatividade" da saída.

  • Temperatura baixa (ex.: 0,2) → respostas mais determinísticas, repetitivas, conservadoras.
  • Temperatura alta (ex.: 0,9) → respostas mais variadas, criativas, imprevisíveis.

Para tarefas clínicas, em geral se prefere temperatura baixa.

Token

Unidade mínima de texto com que o modelo opera. Uma palavra curta é, em geral, um token; uma palavra longa pode ser dividida em vários.

Treinamento

É a fase em que o modelo aprende, ajustando parâmetros (cara, lenta, feita pela empresa que constrói o modelo).
